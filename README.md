# XenoTravel

가볍고 웹 친화적인 해외여행 일정 플래너. 첫 버전은 **혼자 쓰는 버전**이며, 여행은 이 브라우저(localStorage)에만 저장된다.

## 실행

```bash
npm start        # http://localhost:5173
npm test         # 모델·링크 파서 단위 테스트
```

빌드 과정과 설치할 패키지가 없다. Node 20 이상만 있으면 된다.

## 기능

- 여행 만들기: 여행지, 날짜를 넣으면 날짜 수만큼 일차(Day)가 생긴다.
- 장소 추가 (해외 어디든)
  - 검색: OpenStreetMap 기반 Photon API, 지도 중심 근처 결과 우선
  - 링크 붙여넣기: 구글맵 장소 링크, 애플맵, OpenStreetMap, `위도, 경도`
    - 구글맵 짧은 링크(`maps.app.goo.gl`)는 브라우저 보안 정책(CORS) 때문에 열 수 없어서 안내 문구를 보여준다.
  - 지도에서 직접 찍기
- 보기 방식 토글
  - 기본형: 일차가 위아래로 쌓이는 목록
  - 보드형: 트렐로처럼 `요즘 뜨는 곳 → 장소 보관함 → Day 1 …` 칸이 가로로 놓이고, 카드를 끌어 옮긴다. 지도는 숨길 수 있다.
- 요즘 뜨는 곳 (트렌드): 여행지와 가장 가까운 도시의 신규 오픈·기간 한정 장소를 카드로 보여준다. 카드를 끌거나 "+ 담기"를 누르면 요약과 출처 링크가 함께 일정에 들어간다. 지도에는 ★로 표시된다.
- 숙소: "추가할 곳"에서 🏨 숙소로 추가를 고르고 체크인 일차와 박 수(기본 2박)를 정하면, 그 기간의 Day마다 출발·귀가 숙소로 들어간다.
  - 출발 = 전날 밤 숙소, 귀가 = 그날 밤 숙소. 숙소를 옮기는 날은 "출발 A(체크아웃) → 귀가 B(체크인)"로 보인다.
  - 첫날 출발과 마지막 날 귀가는 인접한 숙소로 채운다. 중간에 숙소가 빈 밤은 비워 두고, 그날 제목 옆 🏨+로 채운다.
  - 지도의 동선은 출발 숙소 → 장소들 → 귀가 숙소 순서로 이어진다. 엑셀과 PDF에도 포함된다.
- 항공편: 상단 "✈ 항공편"에서 출국·여행 중 이동·귀국편을 입력한다(편명, 공항, 현지 출발·도착 시각, 예약번호, 메모).
  - 출국·이동편은 그날 맨 위, 귀국편은 맨 아래에 표시된다. 밤 비행기는 출발일과 도착일 양쪽에 보인다.
  - 첫날 출국편이 있으면 출발 숙소를, 마지막 날 귀국편이 있으면 귀가 숙소를 자동으로 채우지 않는다.
  - 자동 조회(편명으로 시간 채우기)는 유료 항공 API가 필요해 아직 없다.
- 장소 보관함: 플랜 영역 아래에 고정되어 일정이 길어도 항상 보인다. 카드의 "보낼 날"로 끌지 않고 원하는 날로 보낼 수 있고, 장소 편집 창에서도 다른 날로 옮길 수 있다.
- 모달(내 여행·항공편)은 바깥을 클릭하면 닫힌다.
- 지도 우클릭(모바일은 길게 누르기): "이 위치 추가" 창에서 일정에 추가하거나 숙소로 추가한다.
- 장소 카드 복제(⧉): 원본 바로 아래에 같은 카드를 만든다. 끌어서 다른 날로 옮기면 된다.
- 끌어서 순서·날짜 변경, 장소 보관함(날짜 미정), 시간·메모·링크 입력, 시간순 정렬
- 지도: 일차별 색상과 번호, 동선 선. 일차 제목을 누르면 그날만 강조한다.
- 내보내기
  - 엑셀(.xlsx): 일차, 날짜, 순서, 시간, 장소, 주소, 메모, 링크, 구글맵 링크
  - PDF: 일차별 지도와 일정표가 담긴 인쇄 미리보기를 연 뒤 브라우저의 "PDF로 저장"을 쓴다.
  - 백업(JSON): 다른 브라우저나 기기로 옮길 때 쓴다.

## 구조

```
server.js            정적 파일 서버 (의존성 없음)
public/index.html    화면
public/app.js        UI·지도·이벤트
public/lib/model.js  여행 데이터 모델 (순수 함수, 테스트 대상)
public/lib/links.js  지도 링크 / 좌표 파서 (테스트 대상)
public/lib/geo.js    장소 검색 / 역지오코딩 (Photon)
public/lib/store.js  localStorage 저장
public/lib/export.js 엑셀·JSON 내보내기
public/lib/trends.js 트렌드 도시 선택·기간 필터 (테스트 대상)
public/data/trends.json 트렌드 데이터
test/                node:test 단위 테스트
```

외부 라이브러리는 CDN(cdnjs)에서 고정 버전으로 불러온다: Leaflet 1.9.4, SortableJS 1.15.2, SheetJS 0.18.5.

## 트렌드 데이터 (`public/data/trends.json`)

- 현재 도시: 도쿄, 오사카, 교토, 후쿠오카 (2026-11-17 웹 조사)
- 장소마다 `status`(new / event / upcoming / classic), 기간(`since`, `until`), 요약, 출처 링크를 담는다. `approx: true`는 대략적인 위치라는 뜻이다.
- 끝난 이벤트(`until`이 지난 것)는 화면에서 자동으로 빠진다.
- 갱신 방법: 같은 형식으로 파일을 고친 뒤 `npm test`를 실행해 필드·좌표를 검증한다. 7일마다 자동으로 조사하는 배치는 다음 단계다.
- 출처마다 날짜가 다를 수 있어서 방문 전 공식 사이트 확인이 필요하다.

## 알려진 한계와 다음 단계

- 지도 타일(OpenStreetMap)과 검색(Photon)은 무료 공개 서버다. 개인 사용은 괜찮지만 사용자가 늘면 키 기반 서비스(MapTiler, Stadia, Google Places 등)로 바꿔야 한다.
- 검색 결과 이름은 영어나 현지어로 나온다 (Photon은 한국어를 지원하지 않는다).
- 작은 가게나 맛집은 OSM 데이터에 없을 수 있다. 이럴 때는 구글맵 링크를 붙여넣는 게 가장 확실하다.
- 다음 단계: 친구와 함께 편집하기 (링크 공유와 실시간 동기화, 서버 필요)
