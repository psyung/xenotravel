# XenoTravel 디자인 및 브랜드 원칙

이 문서는 XenoTravel의 시각적 정체성과 UI 일관성을 유지하기 위한 디자인 원칙을 정의합니다.

---

## 1. 브랜드 디자인 방향: 에디토리얼 카토그래피 (Editorial Cartography)
* XenoTravel은 항공권 예매 사이트나 투박한 스프레드시트가 아닌, **종이 지도와 여행 노트를 디지털로 옮긴 감각적인 아카이브 플래너**를 지향합니다.
* 화면의 90% 이상은 맑은 **쿨 오프화이트(`#F5F8FC`)와 잉크 네이비(`#0F1E2E`)**의 뼈대로 정돈하여 사용자의 여행 일정과 지도 정보 자체가 주인공이 되도록 만듭니다.
* 강조색은 **오션 블루(`#0A6FC2` / 다크 `#4AA8F5`)** 한 가지입니다. 2026-11 모바일 레퍼런스 조사(`docs/design/mobile_references_and_palettes.md`)에서 여행 앱이 가장 많이 쓰는 하늘·바다 계열을 반영한 시안 A를 채택했습니다. (이전: 차콜 + 테라코타 코랄 `#D94E34` — 갈색기가 돌고 일차 색 구분이 안 되어 교체)

---

## 2. 컬러 사용 위계 원칙
1. **블루는 토큰으로만:** 브랜드 블루는 `--accent`/`--cta` 토큰(`#0A6FC2` / 다크 `#4AA8F5`)으로만 씁니다. OS 기본 파란색(`#2563EB`)이나 임의의 파란 값을 하드코딩하지 않습니다. 강조색을 글자로 쓸 때도 흰 바탕·`--bg`·`--accent-soft` 위 4.5:1 이상을 지킵니다.
2. **네이비 vs 블루 역할 분리:**
   * **잉크 네이비 (`#0F1E2E` / 다크 `#EEF3F8`):** 구조적 골격(활성 메인 탭, 일차 선택 필, 텍스트, 로고 경로 본체)
   * **오션 블루 (`#0A6FC2` / 다크 `#4AA8F5`):** 기본 확인 버튼(CTA), 활성 언어 표시, 체크 완료 마크, 길찾기 링크, 목적지 로고 포인트(파비콘은 더 밝은 `#0B84E3`)
   * **보조 오렌지 (`#C2410C` / 다크 `#FDBA74`):** 항공편, '요즘 뜨는 곳' — 블루와 보색으로 구분
3. **일차 색 8개:** 지도 핀·동선은 일차마다 색상환에서 고르게 벌린 색(`#0A6FC2` 블루, `#C2410C` 오렌지, `#0F7B5F` 그린, `#6D4AE8` 보라, `#C7254E` 로즈, `#0E7490` 시안, `#92400E` 브라운, `#475569` 슬레이트)을 씁니다. 흰 번호 글자 대비 5:1 이상.
4. **다크 모드 명도 대비 원칙:**
   * 다크 모드 배경은 완전한 `#000000` 대신 눈의 피로를 줄이는 딥 네이비(`#0D141C`)와 카드 표면(`#151F2A`)을 사용하며, 모든 텍스트와 버튼은 WCAG AA 명도 대비 기준(4.5:1 이상)을 충족해야 합니다.

## 3. UI 컴포넌트 및 인터랙션 디테일 원칙
1. **미니멀 헤더 구성:**
   * 상단 헤더는 `[브랜드 로고 + 여행 선택 드롭다운]`과 `[KO EN 中 日 인라인 스위처 | 다크모드 토글 | 메뉴]`로 간결하게 유지합니다.
   * 브라우저 기본 `<select>` 화살표나 불필요한 장식 박스를 배제합니다.
2. **촉각적(Tactile) 상태 피드백:**
   * 지도 `'종류별'` 필터 버튼, 체크리스트 탭, 일차 필터 필은 눌렀을 때 활성 상태가 즉각적으로 구분되어야 합니다.
   * 지도 `'종류별'` 필터가 켜지면 해당 종류 핀에 **보케 잔상 펄스(Bokeh Pulse Halo)** 를 줍니다. 코어는 선명하게 두고, 카테고리 고유 색의 2중 반투명 빛망울(안쪽 링은 은은하게 유지, 바깥 링은 1.0→1.85배로 퍼지며 사라짐, 약 2초 `ease-in-out` 반복)로 '빛나는 핀'을 표현하며, 나머지 핀은 `opacity: 0.25`로 눌러 대비를 만듭니다.
   * 반짝임은 `transform`·`opacity`만 애니메이션하고, 후광은 `pointer-events: none`으로 터치 영역을 넓히지 않으며, 동작 줄이기 설정에서는 고정 후광 링만 남깁니다. 필터 해제나 `'일차별'` 전환 시에는 즉시 사라져야 합니다.
   * 비활성 텍스트 버튼에는 `user-select: none`을 적용해 모바일/데스크톱 클릭 시 텍스트가 파랗거나 회색으로 드래그 선택되는 현상을 방지합니다.
3. **비침습적 펼침/접힘 동선:**
   * 타임라인 장소 카드는 평소에는 컴팩트한 1~2줄 요약 카드로 유지해 전체 일정 흐름을 한눈에 보여주고, 클릭 시 상세 편집 폼으로 확장되며 바깥 영역 클릭 시 자연스럽게 닫힙니다.
4. **숫자 정렬 가독성:**
   * 시간(`10:00`), 거리(`1.4km`), 예산 및 환율 금액(`¥1,500`, `₩13,500`)에는 `font-variant-numeric: tabular-nums`를 적용해 숫자가 변해도 레이아웃이 흔들리지 않게 합니다.
