# XenoTravel 디자인 및 브랜드 원칙

이 문서는 XenoTravel의 시각적 정체성과 UI 일관성을 유지하기 위한 디자인 원칙을 정의합니다.

---

## 1. 브랜드 디자인 방향: 에디토리얼 카토그래피 (Editorial Cartography)
* XenoTravel은 항공권 예매 사이트나 투박한 스프레드시트가 아닌, **종이 지도와 여행 노트를 디지털로 옮긴 감각적인 아카이브 플래너**를 지향합니다.
* 화면의 90% 이상은 차분한 **웜 오프화이트(`#FAF9F6`)와 차콜 블랙(`#18181B`)**의 무채색 뼈대로 정돈하여 사용자의 여행 일정과 지도 정보 자체가 주인공이 되도록 만듭니다.
* 시선이 반드시 머물러야 하는 **지도 위 핀, 이동 경로, 현재 선택된 언어, 핵심 행동 유도 지점**에만 **테라코타 코랄(`#D94E34` / 다크 `#F2745B`)** 한 가지를 정밀하게 사용합니다.

---

## 2. 컬러 사용 위계 원칙
1. **파란색 배제 원칙:** OS 기본 파란색(`#2563EB` 등)은 지도 바탕의 강/바다 색상과 충돌하고 일반 폼 페이지 인상을 주므로 브랜드 UI 요소에 사용하지 않습니다. (단, 지도 내 `'맛집'`/`'쇼핑'` 등 다중 카테고리 구분을 위한 보조 시맨틱 색상 토큰은 예외로 합니다.)
2. **차콜 vs 코랄 역할 분리:**
   * **차콜 (`#18181B` / 다크 `#F4F4F5`):** 구조적 골격(활성 메인 탭, 일차 선택 필, 기본 확인 버튼, 텍스트, 로고 경로 본체)
   * **테라코타 코랄 (`#D94E34` / 다크 `#F2745B`):** 여정의 하이라이트(지도 번호 핀, 경로 폴리라인, 활성 언어 표시, 체크 완료 마크, 길찾기 링크, 목적지 로고 포인트)
3. **다크 모드 명도 대비 원칙:**
   * 다크 모드 배경은 완전한 `#000000` 대신 눈의 피로를 줄이는 깊은 차콜(`#121214`)과 카드 표면(`#1C1C1F`)을 사용하며, 모든 텍스트와 버튼은 WCAG AA 명도 대비 기준(4.5:1 이상)을 충족해야 합니다.

---

## 3. UI 컴포넌트 및 인터랙션 디테일 원칙
1. **미니멀 헤더 구성:**
   * 상단 헤더는 `[브랜드 로고 + 여행 선택 드롭다운]`과 `[KO EN 中 日 인라인 스위처 | 다크모드 토글 | 메뉴]`로 간결하게 유지합니다.
   * 브라우저 기본 `<select>` 화살표나 불필요한 장식 박스를 배제합니다.
2. **촉각적(Tactile) 상태 피드백:**
   * 지도 `'종류별'` 필터 버튼, 체크리스트 탭, 일차 필터 필은 눌렀을 때 활성 상태가 즉각적으로 구분되어야 합니다.
   * 비활성 텍스트 버튼에는 `user-select: none`을 적용해 모바일/데스크톱 클릭 시 텍스트가 파랗거나 회색으로 드래그 선택되는 현상을 방지합니다.
3. **비침습적 펼침/접힘 동선:**
   * 타임라인 장소 카드는 평소에는 컴팩트한 1~2줄 요약 카드로 유지해 전체 일정 흐름을 한눈에 보여주고, 클릭 시 상세 편집 폼으로 확장되며 바깥 영역 클릭 시 자연스럽게 닫힙니다.
4. **숫자 정렬 가독성:**
   * 시간(`10:00`), 거리(`1.4km`), 예산 및 환율 금액(`¥1,500`, `₩13,500`)에는 `font-variant-numeric: tabular-nums`를 적용해 숫자가 변해도 레이아웃이 흔들리지 않게 합니다.
