## 2단계: 핵심 기능 4종

1. **일차 간 이동·복제 · 일자 순서** (`lib/dayops.js`)
   * 카드의 `⇄` / 편집 창의 `다른 일차로 이동`·`다른 일차로 복제` → 대상 일차 선택 → 미리보기(들어갈 자리, 그날 항공편, 출발·귀가 숙소, 새로 생기는 시간 충돌) → 확정.
   * 일차 도구 `일자 순서` → 날짜 칸은 고정, 장소 묶음을 끌기(SortableJS, 터치 지연 120ms)나 ↑↓ 버튼으로 이동, 충돌 미리보기 → 확정.
   * 모든 작업은 실행 취소 스택에 따로 쌓여 5초 안에 연속으로 되돌린다.
2. **일정 요약 이미지** (`lib/summary.js`): 공유 창 `이미지로 저장`. 여행명·날짜·일차별 대표 장소(최대 3곳)·좌표 동선(타일 없이)만 그린다. 메모·주소·예약번호·가계부는 모델 단계에서부터 넣지 않는다. 언어·라이트/다크를 따르고 오프라인에서도 만든다. 파일명 `xenotravel-summary-{여행명}-{날짜}.png`.
3. **스마트 체크리스트** (`public/data/checklist-presets.json`, 네 언어 35개): 여행 성격(출장·휴양·쇼핑·도시 관광·아이 동반) + 기간(1~3 / 4~7 / 8일+, 여행 일수로 자동 선택) → 이미 있는 항목(어느 언어로 넣었든, 기본 항목 포함) 자동 제외 → 미리보기에서 고른 것만 추가. 기존 항목은 읽기만 한다. 루트 `data/`는 공유 링크 저장소라 git에서 제외되어 있어 `public/data/`에 둔다.
4. **환율 스냅샷 · 결제수단**: 지출마다 `ccy`(적은 통화)·`rate`(적용 환율)·`base`/`baseRate`(기준 통화 환율)를 남겨 환율을 바꿔도 과거 환산액이 그대로. 목록에 적용 환율 표시. 결제수단 필터 칩(수단별 합계·건수). 예전 백업은 `normalizeExpenses()`로 기본값(카드·기타·출발 전·현지 통화·원화÷금액 환율) 채움.
