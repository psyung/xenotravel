### 1. 2차 안정화 10대 항목 라이브 검증 (Pass / Partial / Fail)
아래 수정 사항들이 모바일(337px~449px)과 데스크톱, 라이트/다크모드, 4개 국어 환경에서 부작용 없이 동작하는지 검증해 줘.
1. **다크 탭 파비콘 대비:** 어두운 브라우저 탭 배경에서도 로고의 경로 획과 테라코타 코랄 포인트가 선명하게 구분되는지
2. **지도 보케 핀 접근성 & 모바일 부하 제한:** `prefers-reduced-motion` 환경에서 정적 후광 폴백이 동작하고, 모바일에서 다수 핀 필터링 시 프레임 저하 없이 부드러운지
3. **지도 '종류별' 0건 안내 & 폴리라인 감쇠:** 해당 카테고리 장소가 0개일 때 안내 피드백이 뜨고, 필터 활성 시 경로 선 투명도가 낮아져 활성 핀이 돋보이는지
4. **장소 카드 바깥 클릭 8px 드래그 구분:** 모바일 터치 스크롤 및 지도 드래그 시에는 카드가 닫히지 않고, 제자리 탭/클릭 시에만 정확히 닫히는지
5. **337px 다국어(EN/JA) 헤더 & 체크리스트 탭 보호:** 영어/일본어 전환 시에도 337px 폭에서 텍스트 잘림이나 줄바꿈 깨짐이 없는지
6. **사용자 수정 샘플 여행 보호(`isUserModified`):** 샘플 여행의 장소/메모를 수정한 뒤 언어를 바꿔도 수정한 여행 데이터가 초기화되거나 섞이지 않고 보존되는지
7. **모바일 지도 스크롤 트랩 해소:** 모바일에서 한 손으로 페이지 상하 스크롤 시 지도 영역에 갇히지 않고 부드럽게 이동되는지
8. **체크리스트 일괄 삭제 5초 Undo & 가계부 피드백:** 상단 삭제 후 5초 내 실행 취소가 정상 복구되며, 가격 연동 항목의 가계부 반영/유지 건수가 명확히 안내되는지
9. **타임라인 카드 메모 2줄 말줄임:** 긴 예약 메모 입력 시 목록 카드가 과도하게 길어지지 않고 2줄로 정돈되며, 펼침 시 전체 내용이 보이는지
10. **공유 모달 2,000자 초과 시 백업 바로 저장 버튼:** 경고 노출 시 모달 내부에서 즉시 `.json` 백업 파일을 저장할 수 있는지

### 2. 신규 고도화 기능(P0 ~ P2) 실사용 검증 (Pass / Partial / Fail)
1. **외부 지도 길찾기 딥링크 (Google Maps / Apple Maps / 중국 권역 Amap·바이두):** 출발지-목적지 좌표 전달과 버튼 노출 조건이 정확한지
2. **다중 통화 환율 자동 환산 및 더치페이 정산기:** 현지 통화 입력 시 기준 통화 환산 합계와 결제자/분담자별 최소 송금 정산 계산이 오차 없이 동작하는지
3. **항공편 시차 및 일정 시간 겹침 감지:** 시간 역전/충돌 시 경고 배지와 이후 일정 일괄 밀기 기능이 자연스럽게 동작하는지
4. **표준 `.ics` 캘린더 내보내기 & A4 인쇄 핸드북 뷰:** `.ics` 파일 생성 무결성과 인쇄 미리보기(`@media print`) 레이아웃 가독성이 깔끔한지
5. **오프라인 타일 캐싱 & SVG 벡터 동선 미니맵 폴백:** 오프라인 상태에서 타일 미로드 시 좌표 기반 벡터 미니맵(방위, 연결선, 거리)이 정상 표시되는지
