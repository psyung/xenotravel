### 3차 마감 패치 12개 항목 최종 검증 (Pass / Partial / Fail)
1. **[B1] 지도 일차 필터 우선순위:** 특정 일차(Day 1)만 볼 때 '종류별' 필터를 눌러도 다른 일차 핀이 다시 밝아지거나 펄스되지 않는지
2. **[B2] 샘플 장소 카테고리 다양화:** 도쿄 샘플 여행 장소들에 관광·맛집·카페·쇼핑·숙소 카테고리가 고르게 지정되어 필터별 펄스가 정상 동작하는지
3. **[B3] 숙소 0건 문구 자연스러움:** 숙소 필터 0건 시 "이 일차에 등록된 숙소가 없어요"(4개 국어 포함)로 매끄럽게 출력되는지
4. **[B4] 실행 취소 버튼 명도 대비:** 라이트/다크 토스트 모두에서 '실행 취소' 버튼 대비가 4.5:1 이상으로 선명한지
5. **[B5] 모바일 '지도' 전용 탭 풀사이즈 & 범례 접기:** 모바일 독립 지도 탭이 하단 탭바 위까지 꽉 차게 렌더링되고 범례 접기/펼치기가 동작하는지
6. **[B6] 공유용 파일명 분리:** 공유 모달 내 저장 버튼이 '공유용 일정 파일 저장'으로 표기되고 전체 백업과 다른 파일명으로 저장되는지
7. **[B7] 항공편 시간 충돌 분기:** 귀국편 출발 이후 배치된 일정에는 '30분 밀기' 대신 항공편 시간 확인 안내만 표시되는지
8. **[B8] 다크 브라우저 탭 파비콘 시인성:** OS가 라이트 모드이고 브라우저만 다크 테마여도 파비콘의 밝은 배지 배경 덕분에 로고가 선명히 보이는지
9. **[B9] 공유 모달 404 제거 & 글자 수 게이지:** /api/share 404 콘솔 오류가 사라지고 실시간 공유 링크 글자 수 게이지가 표시되는지
10. **[B10] Esri 타일 영구 캐싱 중단:** Esri 타일이 Service Worker 영구 캐시에 적재되지 않고 오프라인 시 SVG 벡터 미니맵 폴백으로 자연스럽게 전환되는지
11. **[C1] 가계부 기준 통화 선택:** KRW 외에 USD, JPY, EUR 등 기준 통화를 변경할 수 있고 총합과 더치페이 정산이 선택한 통화로 정확히 계산되는지
12. **[C2] 체크리스트 개별 삭제 5초 Undo:** 개별 항목 삭제 시에도 5초 실행 취소 토스트가 뜨고 클릭 시 항목과 가계부 연동이 원복되는지
