# XenoTravel 통합 수정 및 디자인 개편 작업 지시서 (Codex Patch Spec)

이 문서는 라이브 운영 점검과 사용자 피드백을 통해 확정된 **8가지 필수 수정 및 UI/UX 고도화 요구사항**을 정의합니다. 모든 항목은 누락 없이 일괄 반영되어야 합니다.

---

## 작업 1. 브랜드 컬러 시스템 전면 교체 (`Charcoal Monochrome + Terracotta Coral`)

### 현상 및 문제
* 기존 기본 파란색(`#2563EB` 계열)은 일반 관리자 페이지처럼 투박하며, 지도 바탕의 강/바다 파란색과 일정 핀/경로 색상이 겹쳐 지도 위 시인성이 떨어집니다.

### 구현 기준
1. 앱 전역 CSS 변수, Tailwind 설정, 인라인 SVG 및 지도 폴리라인 색상에서 **기존 파란색 Primary 토큰을 완전히 제거**합니다.
2. 구조적 요소(기본 CTA 버튼, 활성 일차 필, 활성 메인 탭)는 **차콜 모노크롬**으로 정돈하고, 핵심 강조 요소(지도 핀, 이동 경로 선, 활성 언어 표시, 주요 배지, 포커스 링)는 **테라코타 코랄(Terracotta Coral)**을 적용합니다.

| 디자인 토큰 역할 | 라이트 모드 (`Light`) | 다크 모드 (`Dark`) | 주요 적용 대상 |
| :--- | :--- | :--- | :--- |
| **앱 전체 배경 (`--bg-app`)** | `#FAF9F6` | `#121214` | 최상위 페이지 캔버스 배경 |
| **카드/패널 배경 (`--bg-surface`)** | `#FFFFFF` | `#1C1C1F` | 일정 카드, 모달, 상단 헤더, 입력 폼 |
| **경계선 (`--border-subtle`)** | `#E7E5E4` | `#2E2E32` | 카드 보더, 구분선, 입력창 테두리 |

## 작업 2. 브랜드 로고 및 파비콘 교체 (비행기 아이콘 폐기)

### 현상 및 문제
* 기존 비행기 아이콘은 항공권 예매 사이트처럼 보여 서비스 정체성과 맞지 않습니다.

### 구현 기준
1. 앱 헤더, 홈 히어로, 파비콘, PWA 아이콘에서 비행기 SVG를 모두 제거합니다.
2. 최종 확정된 **비대칭 S-곡선 경로 + 출발 링 + 분리형 테라코타 코랄 목적지 포인트** 심볼(`public/icons/logo-xeno-route.svg`)을 적용합니다.
3. 상세 SVG 코드와 적용 규격은 `docs/LOGO_GUIDELINES.md`를 그대로 따릅니다.

## 작업 3. 헤더 언어 선택기 개편 (미니멀 인라인 스위처 `KO EN 中 日`)

### 현상 및 문제
* 현재 헤더의 지구본 아이콘 알약 버튼과 브라우저 기본 `<select>` 드롭다운(`KO · 한국어`)은 투박하고 헤더 가로 공간을 과도하게 차지합니다.

### 구현 기준
1. `<select>` 드롭다운, 지구본 아이콘, 중점(`·`) 표기를 모두 제거합니다.
2. 헤더 우측 다크모드 버튼 왼쪽에 **`KO` `EN` `中` `日`** 4개의 인라인 버튼 그룹을 가로 1행으로 배치합니다.
3. **활성 언어 스타일:** 테라코타 코랄(`#D94E34` / 다크 `#F2745B`) 텍스트 컬러 + `font-weight: 800`으로 강조합니다.
4. **비활성 언어 스타일:** 차분한 보조 텍스트 컬러(`#71717A` / 다크 `#A1A1AA`) + `font-weight: 500`, 호버 시 기본 텍스트 컬러로 전환합니다.
5. **반응형 기준:** `337px` 초소형 모바일 뷰포트에서도 4개 버튼이 줄바꿈되지 않고 좌측 여행 제목 및 우측 다크모드/메뉴 버튼과 겹치지 않도록 버튼 간 간격(`gap: 6px`~`8px`)과 패딩을 최적화합니다.

## 작업 4. 다크 모드 1-클릭 즉시 전환 버그 수정

### 현상 및 문제
* 첫 화면 접속 후 다크 모드 달 아이콘을 누를 때 한 번에 바뀌지 않고 **두 번 눌러야 다크 모드로 전환**되는 버그가 있습니다. (초기 내부 상태가 `'system'`으로 잡혀 첫 클릭이 `'system' -> 'light'`로 소비되는 3상태 순환 문제)

### 구현 기준
1. 테마 상태 순환에서 중간 `'system'` 단계를 제거하고, 토글 버튼은 항상 **`light` ↔ `dark` 2상태 직접 반전**으로 동작하게 수정합니다.
2. 앱 초기 마운트 시:
   * `localStorage`에 저장된 사용자 선택값(`'light'` 또는 `'dark'`)이 있으면 그 값을 즉시 적용합니다.
   * 저장된 값이 없으면 `window.matchMedia('(prefers-color-scheme: dark)').matches` 결과를 판별해 초기 상태를 `'dark'` 또는 `'light'`로 확정하고 `<html>` 클래스와 동기화합니다.
3. 따라서 현재 화면이 밝은 상태라면 첫 번째 클릭에 즉시 `'dark'`로, 어두운 상태라면 첫 번째 클릭에 즉시 `'light'`로 100% 전환되어야 합니다.

## 작업 5. 장소 상세 카드 바깥 영역 클릭 시 닫힘 처리

### 현상 및 문제
* 타임라인에서 장소 카드를 눌러 편집 폼이 길게 펼쳐진 뒤, 카드를 다시 접으려면 상단 제목 줄까지 스크롤해 다시 클릭해야 해서 불편합니다.

### 구현 기준
1. 타임라인에서 특정 장소 카드가 펼쳐진(`expanded`) 상태일 때, **해당 카드 영역 바깥을 클릭/탭하면 카드가 자동으로 접히도록** 구현합니다.
2. **필수 예외 처리 (오작동 방지):**
   * **지도 영역 제외:** 펼쳐진 카드를 보면서 우측(또는 상단) 지도를 드래그하거나 핀을 확인하는 경우가 많으므로, **지도 컨테이너(`map` 영역) 및 지도 컨트롤 클릭 시에는 카드가 닫히지 않아야 합니다.**
   * **모바일 스크롤 오작동 방지:** 모바일 터치 환경에서 화면을 위아래로 스크롤하려고 카드 바깥을 터치해 드래그할 때는 닫히지 않고, **포인터 이동 거리가 `8px` 미만인 정지 상태의 탭/클릭일 때만** 닫히도록 처리합니다.
   * **입력 포커스 보호:** 카드 내부의 `<input>`, `<textarea>`, `<select>`, 시간 피커 팝업 조작 중에는 닫히지 않아야 합니다.
3. **시각적 접기 버튼 병행:** 펼쳐진 카드 우측 상단에도 위쪽 화살표(`^`) 접기 아이콘 버튼을 함께 배치해 사용자가 직관적으로 닫을 수 있게 합니다.

## 작업 6. 지도 상단 '종류별' 범례를 인터랙티브 필터 칩으로 개선

### 현상 및 문제
* 지도 좌측 상단 `'종류별'` 전환 시 하단 박스에 표시되는 `관광`, `맛집`, `카페`, `쇼핑`, `기타`, `숙소`가 단순 텍스트 범례로 되어 있어, 클릭해도 필터링이 되지 않고 브라우저 텍스트 드래그 선택(회색 음영)만 발생합니다.

### 구현 기준
1. `관광`, `맛집`, `카페`, `쇼핑`, `기타`, `숙소` 6개 항목을 모두 클릭 가능한 `<button type="button">` 필터 칩으로 구현하고 `user-select: none`을 적용합니다.
2. **필터 활성화(ON) 시각 효과:**
   * 특정 카테고리(예: `쇼핑`)를 클릭하면 해당 버튼이 전구처럼 켜지듯 **카테고리 고유 컬러의 연한 배경 채움 + 카테고리 컬러 테두리 + 굵은 글씨(`font-weight: 700`) + 미세한 글로우/링** 스타일로 밝아집니다.
   * 지도 캔버스 위에서는 **선택된 카테고리에 해당하는 장소 핀만 선명하게(100% 불투명 + 살짝 확대) 강조**되고, 나머지 카테고리 핀은 흐리게(`opacity: 0.25`) 처리됩니다.
3. **필터 해제(OFF) 동작:**
   * 이미 활성화된 카테고리 버튼을 한 번 더 클릭하거나, 상단 토글을 `'일차별'`로 전환하면 필터가 해제되어 모든 핀이 기본 밝기로 복귀합니다.

## 작업 7. 외국어(EN/ZH/JA) 헤더 줄바꿈 깨짐 수정 및 4개 국어 데이터 스키마 반영

### 현상 및 문제
* 영어(`EN`) 및 중국어(`ZH`) 전환 시 일차 카드 상단 우측 액션 버튼(`Directions`, `Copy for chat`, `Optimize route` 등)이 길어지면서 좌측 날짜 영역이 눌려 `Day / 1`, `Sat, / Dec / 19`, `第1 / 天`처럼 세로로 찢어집니다.
* 외국어 모드에서도 기본 샘플 일정(`센소지`, `도쿄 스카이트리` 등)과 `'최근 인기 장소'` 목록의 이름 및 한 줄 설명이 한국어로 그대로 노출됩니다.

### 구현 기준
1. **일차 카드 헤더 레이아웃 수정:**
   * 좌측 일차 배지(`Day 1`, `第1天`)와 날짜 텍스트(`Sat, Dec 19`, `12月19日 周六`)에 `white-space: nowrap`과 `flex-shrink: 0`을 적용해 어떤 언어에서도 글자가 세로로 쪼개지지 않게 고정합니다.
   * 우측 유틸리티 버튼 그룹은 가용 폭이 부족할 경우 날짜 옆에서 억지로 줄어들지 않고 **자연스럽게 다음 줄(2행)로 내려가도록** `flex-wrap` 레이아웃으로 분리합니다.
2. **기본 샘플 일정 및 추천 장소 4개 국어 데이터 구조화:**
   * 앱에 내장된 샘플 여행 일정 및 `'최근 인기 장소'` 프리셋 데이터의 장소명과 설명 필드를 단일 한국어 문자열이 아닌 **4개 국어 객체 구조(`{ ko, en, zh, ja }`)**로 정의합니다.
   * 현재 선택된 앱 언어(`lang`)에 맞춰 해당 언어의 이름과 설명을 렌더링하도록 연동합니다.
   * 단, 사용자가 직접 새로 입력하거나 수정한 커스텀 장소명/메모는 사용자 원문을 덮어쓰지 않고 그대로 보존합니다.

## 작업 8. 직전 패치 기능 무결성 및 반응형 안전 여백 검증

아래 항목들이 위 개편 작업 중 손상되지 않고 정상 유지되는지 함께 검증합니다.
1. **지도 선택 일차 동기화:** 상단에서 특정 일차(예: `Day 4`)를 선택한 뒤 지도를 길게 누르거나 우클릭할 때 선택된 `Day 4` 기준으로 `+ 이 위치 추가 (Day 4)` / `숙소로 추가` 팝업이 뜨고 실제 해당 일차에 추가되는지 확인합니다. (`'전체 동선'` 모드에서는 팝업 내 일차 선택기를 제공합니다.)
2. **모바일 체크리스트 카테고리 탭 & 상단 일괄 액션:** `767px` 이하 모바일에서 `출발 전 할 일`, `짐 싸기`, `쇼핑 리스트`가 가로 탭으로 전환되고, 각 카테고리 상단의 `전체 체크`/`전체 해제` 및 `삭제` 버튼이 가계부 지출 연동과 충돌 없이 동작하는지 확인합니다.
3. **모바일 하단 푸터 안전 여백:** `337px`~`449px` 모바일 화면에서 최하단 스크롤 시 `<footer>`의 개인정보처리방침 버튼과 문의 링크가 하단 고정 탭바 또는 플로팅 버튼에 가려지지 않도록 충분한 `padding-bottom`을 유지합니다.
