# XenoTravel 문구 작성 규칙 (K-4)

## 말투

- **앱과 사이트 안내 문구는 해요체**로 쓴다. 소개·문의·가이드 목록·약관 요약·개인정보처리방침 안내 포함.
  - 예: "저장돼요", "고를 수 있어요", "방법이에요"
  - 쓰지 않음: "저장됩니다", "고를 수 있습니다", "방법입니다"
- 예외: 법률 검토를 받은 약관·방침 **본문 조항**은 검토받은 문장 그대로 둔다(정식 오픈 전 검토 예정).
- 가이드 본문도 해요체로 맞춘다. 후기 글은 사용자가 검수하면서 함께 확인한다.
- `scripts/site-copy.mjs`의 한국어 문구에 "-니다"가 들어오면 `test/qa1125.test.js`가 실패한다.

## 번역 톤

| 언어 | 톤 | 예 |
| --- | --- | --- |
| 영어 | 짧고 친근하게, 문장형 대문자(Sentence case) | "Saved. You can undo." |
| 중국어(간체) | 简洁口语, 불필요한 敬语 없음 | "已保存，可以撤销。" |
| 일본어 | です・ます | "保存しました。元に戻せます。" |

## 문장

- 한 문장에 한 가지 안내. 버튼 이름은 동사로 끝낸다("담기", "삭제", "저장").
- 사용자 탓을 하지 않는다: "잘못 입력하셨어요" 대신 "날짜를 다시 골라 주세요".
- 되돌릴 수 있는 동작은 확인 창 대신 [실행 취소] 토스트를 쓴다. 되돌릴 수 없으면 확인 창에 무엇이 사라지는지 숫자로 적는다.
- 용어는 `docs/glossary.md`를 따른다.

## 금지 표현

- "~하시겠습니까?" → "~할까요?"
- "실패하였습니다" → "~하지 못했어요"
- "해당", "상기", "당사" 같은 공문서 단어
- 개발 용어: "저장소", "repository", "localStorage", "API" (개인정보처리방침의 기술 설명 제외)
