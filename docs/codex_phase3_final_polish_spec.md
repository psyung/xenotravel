# XenoTravel 3차 최종 마감 안정화 작업 지시서 (Phase 3 Final Polish)

이 문서는 2차 라이브 QA 리포트에서 도출된 **10건의 잔여 결함(`B1`~`B10`)**과 **보완 요청 2건(기준 통화 선택, 체크리스트 개별 삭제 실행 취소)**을 한 번에 해결하기 위한 최종 마감 지시서입니다.

---

## 1. 지도 필터 및 모바일 지도 레이아웃 정밀 보완 (`B1`, `B2`, `B3`, `B5`)

### [B1] 지도 '종류별' 필터 선택 시 비활성 일차 핀 재점등 버그 수정
* **현재 현상:** 특정 일차(예: `Day 1`)만 선택해 보는 상태에서 `'종류별'` 필터(예: `'기타'`)를 누르면, 흐려져 있던 다른 일차의 같은 카테고리 핀들까지 `opacity: 1`과 보케 펄스가 켜지면서 안내 문구("이 일차...")와 불일치합니다.
* **구현 기준:**
  * 핀 시각 상태 계산 시 **일차 필터 조건을 카테고리 강조 조건보다 최상위 우선순위**로 적용합니다.
  * 현재 선택된 일차에 속하지 않은 핀은 카테고리 일치 여부와 무관하게 항상 비활성 일차 흐림 상태를 유지하며, 보케 펄스 애니메이션도 절대 부여하지 않습니다.

### [B2] 도쿄 샘플 여행 장소별 실제 카테고리 분류 지정
* **현재 현상:** 기본 도쿄 샘플 여행의 7개 장소가 모두 `'기타'`로 등록되어 있어, `'종류별'` 필터에서 `관광`, `맛집`, `카페`, `쇼핑`, `숙소`를 누르면 전부 `0곳` 안내만 노출됩니다.
* **구현 기준:**
  * 내장된 기본 샘플 여행 장소 7곳에 실제 성격에 맞는 카테고리(`관광`, `맛집`, `카페`, `쇼핑`, `숙소` 등)를 고르게 지정하여, 첫 방문 사용자가 `'종류별'` 필터를 눌러볼 때 각 카테고리별 보케 펄스 효과를 즉시 체험할 수 있게 합니다.

### [B3] 0건 안내 칩의 '숙소' 문구 자연스럽게 분리
* **현재 현상:** 숙소 필터 선택 시 0건 안내가 `"이 일차에 등록된 숙소 장소가 없어요"`처럼 어색한 중복 표현으로 출력됩니다.
* **구현 기준:**
  * 카테고리 키가 `'stay'`(숙소)일 때는 4개 국어 사전에서 별도 문구 키를 사용해 자연스럽게 출력합니다.
    * **KO:** `이 일차에 등록된 숙소가 없어요`
    * **EN:** `No stays added for this day`
    * **ZH:** `这一天暂无住宿安排`
    * **JA:** `この日に登録された宿泊先はありません`

### [B5] 모바일 '지도' 전용 탭 전체 높이 확보 및 범례 접기/펼치기 지원
* **현재 현상:** 모바일에서 지도가 별도 `'지도'` 탭에 있음에도 `340px` 높이 제한이 일괄 적용되어, 상단 조작부(`95px`)와 `'종류별'` 범례(`170px`)가 펼쳐지면 실제 지도 캔버스가 절반 가까이 가려집니다.
* **구현 기준:**
  * `340px` 높이 제한(`clamp(240px, 44vh, 340px)`)은 **일정 목록과 지도가 세로로 한 화면에 함께 배치되는 분할 뷰에서만** 적용합니다.
  * 모바일 하단 내비게이션의 **독립 `'지도'` 전용 탭**에서는 상단 헤더부터 하단 탭바 위까지 남은 뷰포트 높이 전체(`calc(100dvh - 헤더높이 - 하단탭바높이)`)를 채우도록 확장합니다.
  * `'종류별'` 카테고리 범례 패널 우측 상단에 **접기/펼치기 토글 버튼**을 추가하여 사용자가 지도를 넓게 볼 때 범례를 접어둘 수 있게 합니다.

## 2. 브랜드 파비콘 및 접근성 명도 대비 보완 (`B4`, `B8`)

### [B8] OS 테마와 무관하게 다크 브라우저 탭에서도 선명한 파비콘 적용
* **현재 현상:** OS는 라이트 모드이고 브라우저만 다크 테마(`#202124`)를 쓰는 경우, 파비콘 SVG의 `@media (prefers-color-scheme: dark)`가 작동하지 않아 어두운 경로 획이 다크 탭 배경에 묻힙니다.
* **구현 기준:**
  * 앱 상단 헤더용 인라인 로고는 현재처럼 투명 배경을 유지하되, **브라우저 탭 파비콘 전용 파일(`public/icons/logo-xeno-route.svg`)**에는 밝은 원형 배지 배경(`#FAF9F6`)과 얇은 경계선(`#E4E4E7`)을 내장합니다.

### [B4] 토스트 '실행 취소(Undo)' 버튼 WCAG AA 명도 대비(4.5:1 이상) 확보
* **현재 현상:** 토스트 알림 내부 `'실행 취소'` 버튼의 명도 대비가 다크 모드 `2.09:1`, 라이트 모드 `4.29:1`로 접근성 기준(`4.5:1`)에 미달합니다.
* **구현 기준:**
  * 라이트/다크 토스트 모두에서 `'실행 취소'` 버튼 텍스트와 배경 간 명도 대비가 **`4.5:1` 이상**이 되도록 고대비 버튼 필 스타일을 적용합니다.
    * **어두운 토스트 배경(`#18181B`) 위 버튼:** 배경 `#F4F4F5` / 텍스트 `#18181B` (대비 15:1 이상) 또는 투명 배경 위 고명도 강조 텍스트 `#FF9E8A` (`font-weight: 700`)
    * **밝은 토스트 배경(`#FFFFFF`) 위 버튼:** 배경 `#18181B` / 텍스트 `#FFFFFF` 또는 고대비 테라코타 텍스트 `#B8371E` (`font-weight: 700`)

## 3. 공유, 시간 겹침, 타일 캐싱 약관 준수 (`B6`, `B7`, `B9`, `B10`)

### [B6] 공유 모달 저장 버튼 명칭 및 파일명 접미사 분리
* **현재 현상:** 공유 모달 내 저장 버튼 이름이 `'백업 파일'`로 표기되어 있으나 실제로는 메모·예약번호가 제외될 수 있는 공유용 사본이 저장되며, 파일명도 전체 백업과 동일해 혼동을 줍니다.
* **구현 기준:**
  * 공유 모달 내 버튼 라벨을 **`'공유용 일정 파일 저장'`**(4개 국어 대응)으로 변경하고, 다운로드 파일명도 전체 백업(`xenotravel-backup-...json`)과 구분되도록 **`xenotravel-share-{여행명}-{날짜}.json`** 형식으로 저장합니다.
  * 개인 메모·예약번호·가계부·체크리스트가 모두 포함된 원본 전체 백업은 상단 더보기 메뉴의 `'전체 백업 저장'` 기능으로 명확히 구분합니다.

### [B9] 미배포 `/api/share` 404 호출 제거 및 사전 용량 안내 강화
* **현재 현상:** 서버리스 DB가 없는 현재 구조에서 존재하지 않는 `/api/share` 엔드포인트를 호출해 404 에러가 발생하며, 긴 일정 공유 시 사후 경고만 뜹니다.
* **구현 기준:**
  * 구현되지 않은 `/api/share` 네트워크 요청을 제거해 콘솔 404 오류를 없애고 클라이언트 압축 URL(`#s=`) 생성으로 즉시 전환합니다.
  * 공유 모달 상단에 **현재 공유 링크 길이 상태 바(예: `1,420 / 2,000자 · 메신저 전송 안전`)**를 실시간 표시하여 2,000자를 넘기 전에도 사용자가 `'메모 제외'` 토글이나 `'공유용 일정 파일 저장'`을 자연스럽게 선택할 수 있게 안내합니다.

### [B7] 시간 겹침 배지 원인별 분기 (항공편 출발 이후 일정 분리)
* **현재 현상:** 귀국편 항공 출발 시각 이후로 일정이 잡힌 경우에도 동일한 `'30분 밀기'` 버튼이 노출되어, 누르면 오히려 비행 출발 시각과 더 멀어지며 겹침이 커집니다.
* **구현 기준:**
  * 시간 충돌 원인을 두 가지로 분기합니다.
    1. **앞뒤 장소 간 시간 역전/중복:** 기존처럼 `시간 겹침` 배지와 **`이후 일정 30분 밀기`** 버튼을 표시합니다.
    2. **귀국편 출발 이후 또는 입국편 도착 이전 배치:** `항공편 시간 확인` 배지를 표시하고 `'30분 밀기'` 버튼 대신 **`항공편 시간 보기`** 또는 **`일정 시간 수정`** 안내만 노출합니다.

### [B10] 지도 타일 오프라인 저장 약관 준수 처리
* **현재 현상:** Esri 위성/지도 타일은 이용 약관상 영구 로컬 재배포·대량 오프라인 저장 제한이 있을 수 있는데 Service Worker Cache에 600장까지 장기 보관하고 있습니다.
* **구현 기준:**
  * Esri 타일 URL에 대해서는 Service Worker 영구 캐시 저장(`cache.put`)을 중단하고 표준 브라우저 HTTP 캐시만 사용하도록 제한합니다.
  * 오프라인 상태에서는 **이미 구현된 좌표 기반 SVG 벡터 동선 미니맵 폴백**이 즉시 활성화되도록 전환 기준을 명확히 연결하여 약관 리스크 없이 안정적인 오프라인 동선 확인을 보장합니다.

## 4. 사용자 편의 추가 보완 2건 (`P0-2` 기준 통화 선택 & 체크리스트 개별 Undo)

### [C1] 가계부 '기준 통화(Base Currency)' 선택 기능 추가
* **구현 기준:**
  * 여행 설정 및 가계부 환율 설정 영역에서 **기준 통화(`KRW`, `USD`, `JPY`, `EUR`, `CNY`, `TWD` 등 주요 통화 선택 드롭다운)**를 직접 고를 수 있게 합니다. (기본값 `KRW`)
  * 선택한 기준 통화 기호와 소수점 자리수 규칙(KRW/JPY는 정수, USD/EUR는 소수점 2자리)에 맞춰 가계부 총합 및 더치페이 정산 송금액이 자동 계산·표시되어야 합니다.

### [C2] 체크리스트 개별 항목 삭제 시 5초 '실행 취소(Undo)' 지원
* **구현 기준:**
  * 카테고리 일괄 삭제뿐 아니라 **개별 체크리스트 항목 우측 삭제 버튼**을 눌렀을 때도 동일한 5초 `'실행 취소'` 고대비 토스트를 노출하여, 모바일에서 잘못 터치해 지운 항목과 연동된 가계부 지출 내역을 즉시 복구할 수 있게 합니다.
