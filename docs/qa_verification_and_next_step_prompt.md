### 1. 직전 패치 8대 항목 라이브 검증 (Pass / Partial / Fail)
아래 항목들이 모바일(337px~449px)과 데스크톱, 라이트/다크모드, 4개 국어 환경에서 부작용 없이 동작하는지 검증해 줘.
1. **브랜드 컬러 및 로고 리뉴얼:** 기존 파란색과 비행기 아이콘이 완전히 제거되었고, 차콜 모노크롬 + 테라코타 코랄(`#D94E34` / 다크 `#F2745B`) 팔레트와 새 브랜드 로고/파비콘이 일관되게 적용되었는지
2. **인라인 언어 스위처 (`KO EN 中 日`):** 투박한 select box 없이 인라인 스위처가 깔끔하게 노출되며, `337px` 모바일 폭에서도 다른 헤더 요소와 겹치지 않는지
3. **다크 모드 1-클릭 전환:** 첫 접속 직후 테마 버튼을 한 번만 눌러도 라이트 ↔ 다크 모드가 즉시 전환되는지
4. **장소 카드 바깥 클릭 닫기:** 펼쳐진 장소 카드 외부를 탭/클릭할 때 자연스럽게 닫히며, 지도 드래그나 모바일 스크롤 시에는 오작동하지 않는지
5. **지도 '종류별' 필터 칩:** `관광/맛집/카페/쇼핑/기타/숙소` 클릭 시 전구처럼 밝아지며 지도 위 해당 카테고리 핀만 강조되고 나머지 핀은 흐려지는지, 텍스트 드래그 음영이 생기지 않는지
6. **외국어 헤더 줄바꿈 & 4개 국어 프리셋 데이터:** `EN`, `ZH`, `JA` 전환 시 일차/날짜 텍스트가 세로로 찢어지지 않고, 샘플 일정 및 최근 인기 장소 이름·설명이 해당 언어로 정상 출력되는지
7. **지도 선택 일차 동기화:** 상단에서 선택한 일차(`Day N`)와 지도 길게 누르기 추가 일차가 정확히 일치하는지
8. **체크리스트 탭/일괄 액션 & 푸터 안전 여백:** 모바일 카테고리 탭 전환, 상단 전체 체크/삭제, 그리고 최하단 푸터 링크가 모바일 하단 바에 가려지지 않는지

### 2. 잔여 오류 및 UX 마찰 점검 (Bugs & Friction)
- 위 8가지 항목 외에 여전히 남아 있는 시각적 어색함, 다크모드 명도 대비 부족, 빈 상태(Empty State) 안내 미흡, 모바일 한 손 조작 불편 등을 **[발생 위치 / 현재 현상 / 개선 기준]** 형식으로 정리해 줘.

### 3. 차기 서비스 고도화 제안 (Next-Level Develop 포인트)
기본 기능과 디자인 완성도가 갖춰진 현 시점에서, XenoTravel을 실제 해외여행 현장에서 대체 불가능한 플래너로 만들기 위한 **다음 단계 고도화 기능**을 우선순위별로 제안해 줘.
- 검토 후보 영역:
  1. **현지 맞춤형 외부 지도 길찾기 딥링크 & 경로 방향 화살표:** Google Maps, Apple Maps, 중국 고덕지도(Amap) 연동을 통한 구간별 실제 길찾기 실행
  2. **다중 통화 실시간 환산 및 동행자 더치페이 정산기:** 현지 통화 입력 시 원화 자동 병기 및 결제자별 최소 송금 정산 요약
  3. **오프라인 현장 대응 강화:** 네트워크 단절 시 일정 반경 지도 타일 로컬 캐싱 및 벡터 개략도 폴백 뷰
  4. **일정 내보내기 확장:** `.ics` 표준 캘린더 일괄 등록 및 인쇄/PDF 전용 일자별 요약표
  5. **항공편 시차 반영 및 일정 시간 충돌 자동 감지 알림**
- 각 제안마다 **[제안 영역 / 현재 한계 / 구체적 구현 방향 / 기대 효과 및 우선순위]** 형식으로 정리해 줘.
