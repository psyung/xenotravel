# XenoTravel 2차 안정화(Edge-Case Polish) 및 핵심 기능 고도화 작업 지시서

이 문서는 1차 브랜드 리뉴얼 및 핵심 버그 수정 이후 진행된 **라이브 QA 점검 결과(잔여 엣지 케이스 10건)**와 **실사용 가치를 극대화할 차기 고도화 로드맵(P0 ~ P2)**을 통합한 Codex 구현 명세서입니다.

---

## Part A. 잔여 결함 및 UX 엣지 케이스 정밀 수정 (10건)

### A-1. 브라우저 다크 탭바 대응 파비콘 명도 대비 보완
* **현상:** 브라우저 자체 UI 테마가 다크 모드(`#18181B`~`#202124`)일 때 `public/icons/logo-xeno-route.svg`의 어두운 획이 배경과 가까워 대비가 낮아 보일 수 있습니다.
* **구현 기준:**
  * `public/icons/logo-xeno-route.svg` 내부 `@media (prefers-color-scheme: dark)` 블록의 `.route, .origin` 색상을 순백에 가까운 `#FAFAFA`로 상향하고, 필요 시 미세한 밝기 대비가 확보되도록 조정합니다. (라이트 탭용 `#18181B`와 테라코타 코랄 `#D94E34` / `#F2745B`는 유지)

### A-2. 지도 '종류별' 핀 보케 잔상 펄스 접근성(`prefers-reduced-motion`) 및 모바일 성능 최적화
* **현상:** 카테고리 필터 선택 시 보케 잔상 펄스는 잘 동작하나, 동작 줄이기 설정 사용자 폴백과 모바일 다수 핀(15개 이상) 렌더링 시 프레임 저하 방어가 필요합니다.
* **구현 기준:**
  1. **접근성 폴백:** `@media (prefers-reduced-motion: reduce)` 환경에서는 무한 반복 깜빡임 애니메이션(`animation: none`)을 끄고, 핀 주변에 은은하게 고정된 반투명 후광 링만 렌더링합니다.
  2. **모바일 뷰포트 부하 제한:** 모바일(`767px` 이하)에서 한 일차에 핀이 15개 이상 밀집된 경우, 현재 지도 화면 경계(`map.getBounds()`) 내에 보이는 핀에만 펄스 애니메이션 클래스를 부여하고 화면 밖 핀은 정적 강조 상태만 유지합니다.

### A-3. 지도 '종류별' 필터 0건 안내(Empty Result) 및 동선 폴리라인 시각적 위계 분리
* **현상:** 선택된 일차에 특정 카테고리(예: `카페`) 장소가 0개일 때 아무 피드백이 없어 미작동으로 오인할 수 있으며, 필터 활성 중에도 전체 경로 폴리라인이 진하게 남아 강조 핀의 시인성을 분산시킵니다.
* **구현 기준:**
  1. **0건 상태 안내:** 선택한 카테고리에 해당하는 핀이 현재 일차에 0개일 경우 지도 상단 필터 바 아래에 비침습적 상태 칩/토스트(`"이 일차에 등록된 {카테고리명} 장소가 없어요"`, 4개 국어 지원)를 표시합니다.
  2. **폴리라인 감쇠:** `'종류별'` 카테고리 필터가 1개 이상 활성화된 동안에는 지도 위 이동 경로 폴리라인의 투명도를 `opacity: 0.25`로 낮춰, 보케 펄스가 켜진 해당 카테고리 핀이 시각적 최상위에 오도록 분리합니다.

### A-4. 장소 상세 카드 바깥 클릭 닫기 — 터치 드래그/스크롤 오작동 차단
* **현상:** 모바일에서 지도를 드래그하거나 화면을 상하 스크롤할 때, 손가락을 떼는 순간 간헐적으로 바깥 클릭으로 판정되어 열어 둔 장소 상세 카드가 닫힙니다.
* **구현 기준:**
  * 전역 바깥 닫기 감지를 단순 `click`이 아닌 **`pointerdown` 좌표 기록 -> `pointerup` 이동 거리 계산** 방식으로 구현합니다.
  * `Math.hypot(upX - downX, upY - downY) >= 8` (8px 이상 이동)인 경우 드래그/스크롤 제스처로 판정하여 카드를 절대 닫지 않습니다.
  * 지도 캔버스 컨테이너 내부 및 카드 내부 입력/버튼 요소 클릭은 기존대로 닫힘 대상에서 제외합니다.

### A-5. `337px` 초소형 모바일 뷰포트 내 다국어(EN/JA) 헤더 및 체크리스트 탭 텍스트 보호
* **현상:** `337px`~`375px` 폭에서 영어(`EN`)나 일본어(`JA`)로 전환하면 단어 길이가 늘어나 헤더 여행 제목이 과도하게 잘리거나 체크리스트 3분할 탭(`출발 전 할 일 / 짐 싸기 / 쇼핑 리스트`) 텍스트가 압박받습니다.
* **구현 기준:**
  1. **체크리스트 모바일 축약 라벨 분기:** `400px` 이하 모바일 뷰포트에서는 3분할 탭에 컴팩트 라벨과 `font-size: 11px`~`12px`, `letter-spacing: -0.02em`을 적용해 4개 국어 모두 한 줄에 균등 배치합니다.
     * `KO`: `출발 전` / `짐 싸기` / `쇼핑`
     * `EN`: `Pre-trip` / `Packing` / `Shopping`
     * `ZH`: `出发前` / `行李打包` / `购物`
     * `JA`: `出発前` / `荷造り` / `買い物`
  2. **상단 헤더 공간 확보:** `375px` 이하에서는 헤더 좌우 패딩과 버튼 간격을 압축해 여행 제목이 최소 45% 이상의 가로 폭을 확보하도록 보장합니다.

### A-6. 다국어 전환 시 '사용자 편집 샘플 여행' 데이터 덮어쓰기 방지
* **현상:** 초기 제공된 샘플 여행 일정에서 사용자가 장소 1~2개를 수정하거나 메모를 입력한 뒤 언어를 바꾸면, 여전히 샘플 여행으로 인식되어 사용자 수정 내역이 다른 언어 샘플로 초기화되거나 데이터가 섞일 위험이 있습니다.
* **구현 기준:**
  * 각 여행 객체에 `isUserModified: boolean` 플래그를 도입합니다. (초기 샘플 생성 시 `false`)
  * 사용자가 샘플 여행에서 **장소 추가, 삭제, 순서 변경, 이름/시간/메모/비용 수정, 숙소 변경, 항공편 입력** 중 하나라도 수행하는 즉시 `isUserModified = true`로 전환합니다.
  * 이후 헤더에서 언어(`KO / EN / 中 / 日`)를 변경할 때, `isUserModified === true`인 여행은 **UI 프레임(메뉴, 버튼, 탭, 안내 문구)만 번역하고 여행 데이터 본문은 절대 덮어쓰지 않고 보존**합니다. (`isUserModified === false`인 순수 미수정 샘플만 새 언어 샘플로 교체)

### A-7. 모바일(`337px`~`449px`) 한 손 스크롤 시 지도 영역 스크롤 트랩(Scroll Trap) 해소
* **현상:** 모바일에서 한 손 엄지로 페이지를 아래로 스크롤할 때 터치 시작점이 지도 캔버스에 걸리면 페이지 전체 스크롤 대신 지도 패닝만 작동해 하단으로 이동하기 어렵습니다.
* **구현 기준:**
  * 모바일 뷰포트(`767px` 이하)에서 지도 컨테이너의 높이를 `clamp(240px, 44vh, 340px)` 범위로 제한하여 상하단 바깥 영역에서 언제든 자연스러운 페이지 스크롤이 가능하도록 터치 영역 비율을 조정합니다.

### A-8. 체크리스트 상단 '삭제' 일괄 실행 실수 복구(Undo) 및 가계부 동기화 피드백
* **현상:** 모바일에서 상단 탭이나 `전체 체크`를 누르려다 인접한 `삭제` 버튼을 잘못 누르면 복구 수단 없이 항목이 즉시 삭제되며, 가격 입력 항목의 일괄 체크/해제/삭제 시 가계부 반영 결과 피드백이 부족합니다.
* **구현 기준:**
  1. **5초 실행 취소(Undo) 토스트:** 카테고리 상단 `삭제` 실행 후 삭제 직전 스냅샷을 메모리에 임시 보관하고, 하단에 **5초간 유지되는 `'실행 취소(Undo)'` 버튼 포함 토스트**를 띄워 클릭 시 항목과 가계부 연동 상태를 원상 복구합니다.
  2. **가계부 연동 결과 명시:** 가격 입력 항목이 포함된 일괄 체크/해제/삭제 시 토스트 문구에 가계부 반영/회수 건수를 함께 안내합니다. (예: `"체크 완료 3건 삭제됨 (가계부 지출 2건은 유지됨)"`)

### A-9. 타임라인 장소 카드 메모 2줄 말줄임 처리 (수직 팽창 방지)
* **현상:** 해외 현지어 상호명, 주소, 예약번호 및 긴 바우처 메모가 입력되면 타임라인 목록 카드 한 장이 지나치게 길어져 전체 일차 동선 조망이 어려워집니다.
* **구현 기준:**
  * 타임라인 목록 상태(접힌 상태)의 장소 카드에서는 메모 텍스트에 `-webkit-line-clamp: 2`를 적용해 최대 2줄까지만 노출하고, 전체 메모는 카드를 클릭해 펼친 상세 편집 상태에서 온전히 열람하도록 정보 밀도를 분리합니다.

### A-10. 공유 링크 2,000자 초과 경고 모달 내 '백업 파일 바로 저장' CTA 직결
* **현상:** 공유 URL이 2,000자를 넘어 경고 배너가 뜰 때, 사용자가 즉시 `.json` 백업 파일을 다운로드하려면 모달을 닫고 상단 더보기 메뉴로 다시 이동해야 합니다.
* **구현 기준:**
  * 공유 링크 길이가 2,000자를 초과해 경고 안내가 노출되는 즉시, 해당 경고 영역 바로 아래에 **`백업 파일(.json) 바로 저장`** 보조 버튼을 렌더링하여 원클릭으로 다운로드할 수 있게 동선을 단축합니다.

## Part B. 다음 단계 핵심 기능 고도화 (Next-Level Feature Roadmap)

모든 기능은 **별도 백엔드 서버 없이 클라이언트 단독(Local-First / Serverless)으로 즉시 동작**하도록 구현합니다.

### [P0-1] 해외 현지 길찾기 외부 지도 원터치 딥링크(Deep Link) 연동
* **목표:** 앱 내 지도에서 동선을 확인한 뒤 해외 현지에서 도보/대중교통 내비게이션을 한 번의 탭으로 실행합니다.
* **구현 기준:**
  * 장소 상세 카드와 지도 핀 팝업에 `'길찾기'` 실행 버튼 그룹을 제공합니다.
  * 장소의 위경도(`lat`, `lng`) 및 직전 장소 좌표(있을 경우 출발지로 자동 설정)를 기반으로 외부 지도 URL을 생성합니다.
    * **Google Maps:** `https://www.google.com/maps/dir/?api=1&destination={lat},{lng}` (직전 장소가 있으면 `&origin={prevLat},{prevLng}` 포함)
    * **Apple Maps:** `https://maps.apple.com/?daddr={lat},{lng}&dirflg=r`
    * **중국 권역 여행지 자동 감지 시 추가 노출:** 여행지 좌표 또는 도시가 중국 본토 권역일 경우 **고덕지도(Amap)** (`https://uri.amap.com/navigation?to={lng},{lat},{name}&mode=bus`) 및 **바이두맵** 웹 길찾기 링크를 함께 표시합니다.

### [P0-2] 해외 현지 다중 통화 환율 자동 환산 및 동행자 더치페이 정산기
* **목표:** 현지 통화(`JPY`, `CNY`, `USD`, `EUR` 등) 지출과 국내 사전 결제(`KRW`)를 통합 계산하고, 2인 이상 동행 시 정산 송금액을 자동 산출합니다.
* **구현 기준:**
  1. **여행별 환율 설정:** 여행 설정(또는 가계부 상단)에서 기준 통화(기본 `KRW`)와 현지 통화 코드, 기준 환율(오프라인에서도 동작하도록 로컬 저장, 예: `100 JPY = 900 KRW`)을 지정합니다.
  2. **가계부 통합 환산 표시:** 지출 등록 시 현지 통화로 입력하면 기준 통화 환산 금액이 자동 계산되어 병기되며, 가계부 상단 요약 바에 **통화별 합계 + 기준 통화 환산 총합**을 동시에 표시합니다.
  3. **동행자 더치페이 정산 요약:** 여행에 동행자 이름 목록(예: `나`, `민수`, `지영`)을 등록할 수 있게 하고, 각 지출 항목에 `결제자`와 `분담 대상`을 체크하면 가계부 내 `'정산하기'` 패널에서 **인당 부담액과 최소 송금 횟수 기준 정산 결과**를 산출하고 메신저 공유용 텍스트로 복사할 수 있게 합니다.

### [P1-1] 항공편 출도착 시간 반영 및 일정 시간 충돌(Time Overlap) 자동 감지
* **목표:** 시차 착오나 빡빡한 일정 배치로 인해 앞뒤 방문 시각이 겹치는 실수를 사전에 감지하고 일괄 보정합니다.
* **구현 기준:**
  * 동일 일차 내 시간(`HH:MM`)이 지정된 인접 장소들 간 선후 관계를 검사하여, 앞 장소보다 뒷 장소 시작 시각이 빠르거나 동일 시각에 겹칠 경우 카드 경계에 테라코타 코랄 경고 배지(`시간 겹침 확인`)를 표시합니다.
  * 함께 노출되는 **`이후 일정 30분씩 밀기`** 유틸리티 버튼을 누르면 해당 지점 이후 시간 지정 일정들의 시각을 일괄 조정할 수 있게 합니다.

### [P1-2] 표준 캘린더(`.ics`) 내보내기 및 A4 인쇄/PDF 전용 '여행 핸드북' 뷰
* **목표:** 개인 스마트폰 기본 캘린더 연동과 입국 심사·부모님/동행자 공유용 출력물 수요를 충족합니다.
* **구현 기준:**
  1. **`.ics` 일괄 다운로드:** 상단 더보기 메뉴에 `'캘린더에 추가 (.ics)'` 액션을 추가하여 항공편, 숙소 체크인/아웃, 시간 지정 장소를 표준 `VCALENDAR` 2.0 포맷 `.ics` 파일로 생성·다운로드합니다.
