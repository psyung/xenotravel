# XenoTravel 용어집 (K-5)

화면 문구는 아래 표준 단어만 쓴다. "쓰지 말 것"에 적은 단어가 앱 문구(`public/lib/messages.js`의 한국어 키)에 들어오면 `test/qa1125.test.js`가 실패한다.

| 뜻 | 표준 (KO) | EN | ZH | JA | 쓰지 말 것 | 예외 |
| --- | --- | --- | --- | --- | --- | --- |
| 항목·여행을 없애는 버튼 | 삭제 | Delete | 删除 | 削除 | 지우기, 지워요, 지웠어요 (삭제 뜻으로) | 데이터 초기화: "이 기기에서 모든 데이터 지우기", "백업 후 지우기", 데이터 지우기 확인 문구. 브라우저가 사이트 데이터를 "지운" 경우 |
| 표시를 없앰 | 풀기 / 해제 | Clear / Uncheck | 取消 | 解除 | 지우기 | |
| 돈을 쓴 한 건 | 지출 | Expense | 支出 | 支出 | 쓴 돈, (명사) 기록 | "기록하기·기록했어요"처럼 동사로는 "기록". 백업 파일의 "기록"(데이터 행)과 "기록 당시 환율" |
| 날짜 단위 | Day N | Day N | 第N天 | N日目 | 일차 (화면 문구) | 엑셀·CSV 열 이름 `일차`(파일 형식이라 그대로) |
| 여러 Day | Day별 · 이전 Day · 다음 Day · 모든 Day | by day · previous/next day | 按天 | 日別 | 일차별 · 이전 일차 | |
| 여행의 시작~끝 | 여행 기간 | Trip dates | 行程日期 | 旅行期間 | 여행 날짜 | 날짜 하나만 고를 때는 "여행 시작일" |

## 날짜 표기

| 자리 | 표기 | 함수 |
| --- | --- | --- |
| 제목·헤더·상세 | 긴 표기 "11월 23일 (월)" | `longDate` (= `M.formatDate`) |
| 칩·탭·카드 보조 줄 | 짧은 표기 "11/23" | `shortDate` |
| 기간 | 언어별 기호 (`~`, `〜`, `–`), 같은 날이면 하나 | `formatRange(a, b)` |

날짜 문자열을 직접 만들지 않는다. 범위 기호를 직접 붙이지 않는다(`test/qa1125.test.js`가 검사).
