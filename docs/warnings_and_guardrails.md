# XenoTravel 개발 경고 사항 및 절대 금지 규칙 (Guardrails)

과거 패치 및 라이브 QA 과정에서 발견된 결함이 재발하지 않도록, 모든 수정과 기능 추가 시 아래 규칙을 반드시 검증해야 합니다.

---

## 1. 브랜드 및 디자인 관련 절대 금지 규칙
* **[금지] 기본 파란색 Primary 스타일 복귀 금지:** 버튼, 활성 탭, 지도 핀, 경로 선, 포커스 링에 `#2563EB` 계열 파란색을 사용하지 마세요. 반드시 차콜(`#18181B` / `#F4F4F5`)과 테라코타 코랄(`#D94E34` / `#F2745B`) 토큰을 사용하세요.
* **[금지] 비행기 아이콘 사용 금지:** 헤더, 홈 화면, 파비콘, 빈 상태 일러스트 어디에도 비행기 아이콘을 넣지 마세요. 브랜드 심볼은 `public/icons/logo-xeno-route.svg`만 사용합니다.
* **[금지] 투박한 언어 `<select>` 박스 재도입 금지:** 언어 전환 UI는 반드시 `KO EN 中 日` 인라인 텍스트 버튼 그룹으로 유지하며, 중점(`·`)이나 지구본 알약 버튼을 추가하지 마세요.
* **[주의] 브라우저 다크 탭바 파비콘 대비 유지:** `logo-xeno-route.svg`의 다크 모드 경로 색상은 어두운 브라우저 탭 배경에서도 윤곽이 묻히지 않도록 `#FAFAFA` 수준의 고명도 대비를 유지하세요.

## 2. 상태 및 터치 인터랙션 버그 방어 규칙
* **[경고] 다크 모드 2번 클릭 버그 재발 금지:** 테마 버튼 클릭 핸들러에서 `'system'` 중간 상태를 거치지 않고 현재 화면 기준 `light ↔ dark` 즉시 반전 로직을 유지하세요.
* **[경고] 장소 카드 바깥 클릭 닫기 시 모바일 드래그 오작동 금지:**
  * 바깥 영역 감지는 반드시 `pointerdown`과 `pointerup` 간 이동 거리가 **`8px` 미만인 단순 탭/클릭**일 때만 실행하세요. 모바일 화면 스크롤이나 지도 패닝 종료 시 카드가 닫히면 안 됩니다.
  * 지도 캔버스 컨테이너 내부 클릭 시에는 카드가 닫히지 않도록 예외 처리하세요.
* **[경고] 샘플 여행 사용자 편집 데이터 덮어쓰기 금지:**
  * 사용자가 기본 샘플 여행의 장소, 메모, 시간, 비용, 숙소를 한 번이라도 수정하면 `isUserModified = true`로 마킹하세요. 이후 언어를 변경할 때 UI 프레임만 번역하고 사용자가 수정한 여행 데이터는 절대 다른 언어 샘플로 덮어쓰지 마세요.
* **[경고] 모바일 지도 스크롤 트랩(Scroll Trap) 방지:**
  * 모바일(`767px` 이하)에서 지도 컨테이너 높이가 화면을 가득 채워 한 손 엄지 스크롤이 막히지 않도록 최대 높이를 `44vh`(`clamp(240px, 44vh, 340px)`) 수준으로 제한하세요.

## 3. 애니메이션, 데이터 및 레이아웃 회귀 방지 규칙
* **[금지] `'예상 걸음(0걸음)'` 부활 금지:** 보행 경로 연동 없이 `0걸음`으로 고정 노출되던 요약 배지는 폐기된 항목입니다. 어떤 화면이나 번역 키에도 다시 추가하지 마세요.
* **[경고] 보케 핀 펄스 접근성 및 성능 보호:**
  * `@media (prefers-reduced-motion: reduce)` 환경에서는 핀 깜빡임 애니메이션을 비활성화하고 고정 후광만 표시하세요.
  * 모바일에서 핀이 15개 이상일 때는 현재 지도 화면(`getBounds()`) 안의 핀에만 펄스 애니메이션을 적용하세요.
* **[경고] 체크리스트 일괄 삭제 실수 복구 및 가계부 오염 방지:**
  * 카테고리 상단 `삭제` 실행 시 복구 수단 없이 영구 삭제되지 않도록 5초 `실행 취소(Undo)` 토스트를 제공하세요.
  * `전체 체크` 시 이미 체크된 항목 금액이 가계부에 중복 합산되지 않도록 멱등성을 유지하세요.
* **[경고] `337px` 초소형 모바일 뷰포트 깨짐 주의:**
  * 영어(`EN`)와 일본어(`JA`) 전환 시 체크리스트 모바일 탭 라벨과 상단 헤더 여행 제목이 잘리지 않도록 모바일 축약 라벨을 적용하고, 최하단 `<footer>` 링크가 모바일 하단 내비게이션 바에 가려지지 않도록 하단 여백을 유지하세요.
