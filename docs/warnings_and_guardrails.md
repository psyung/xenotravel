# XenoTravel 개발 경고 사항 및 절대 금지 규칙 (Guardrails)

과거 패치 과정에서 발생했던 결함이 재발하지 않도록, 아래 항목들은 모든 수정 및 리팩토링 시 반드시 검증해야 하는 **절대 금지 규칙**입니다.

---

## 1. 브랜드 및 디자인 관련 경고
* **[금지] 기본 파란색 Primary 스타일 복귀 금지:** 버튼, 활성 탭, 지도 핀, 경로 선, 포커스 링에 `#2563EB` 계열 파란색을 다시 쓰지 마세요. 반드시 차콜(`#18181B` / `#F4F4F5`)과 테라코타 코랄(`#D94E34` / `#F2745B`) 토큰을 사용하세요.
* **[금지] 비행기 아이콘 사용 금지:** 헤더, 홈 화면, 파비콘, 빈 상태 일러스트 어디에도 비행기 아이콘을 넣지 마세요. 브랜드 심볼은 `public/icons/logo-xeno-route.svg`만 사용합니다.
* **[금지] 투박한 언어 `<select>` 박스 재도입 금지:** 언어 전환 UI는 반드시 `KO EN 中 日` 인라인 텍스트 버튼 그룹으로 유지하며, 중점(`·`)이나 지구본 아이콘 알약 버튼을 추가하지 마세요.

## 2. 상태 및 인터랙션 버그 관련 경고
* **[경고] 다크 모드 2번 클릭 버그 재발 주의:** 테마 버튼 클릭 핸들러에서 `'system'` 상태를 거치게 만들면 라이트 기기 사용자에게 첫 클릭 무반응 버그가 발생합니다. 반드시 현재 화면 기준 `light ↔ dark` 즉시 반전 로직을 유지하세요.
* **[경고] 장소 카드 바깥 클릭 시 지도/스크롤 오작동 주의:**
  * 펼쳐진 장소 카드를 닫기 위해 `document` 전역 `mousedown`/`click` 리스너를 붙일 때, **지도 캔버스 클릭**이나 **모바일 터치 스크롤(`touchmove` 거리 `>= 8px`)**까지 닫힘으로 처리하면 사용자가 지도를 보거나 화면을 내릴 때마다 카드가 닫혀 극심한 UX 스트레스를 유발합니다. 반드시 지도 영역 제외 및 터치 이동 거리 임계값 검사를 포함하세요.
* **[경고] 지도 `'종류별'` 필터 텍스트 선택 음영 주의:** 필터 칩에 `user-select: none`을 누락하면 모바일/데스크톱에서 연타할 때 글자에 회색/파란색 드래그 블록이 생깁니다.

## 3. 데이터 및 레이아웃 회귀 관련 경고
* **[금지] `'예상 걸음(0걸음)'` 부활 금지:** 보행 경로 API 연동 없이 `0걸음`으로 고정 노출되던 요약 배지는 완전히 폐기된 항목입니다. UI, 상태, 번역 키, 테스트 어디에도 다시 추가하지 마세요.
* **[경고] `337px` 초소형 모바일 뷰포트 깨짐 주의:**
  * 상단 헤더에서 `KO EN 中 日` 버튼과 여행 제목이 한 줄에서 겹치지 않는지 반드시 `337px` 폭에서 확인하세요.
  * 페이지 최하단 `<footer>`의 개인정보처리방침 버튼과 이메일 링크가 모바일 고정 하단 내비게이션 바(`bottom nav`) 또는 플로팅 버튼에 가려 클릭이 막히지 않도록 충분한 하단 여백을 유지하세요.
* **[경고] 체크리스트 일괄 조작 시 가계부 지출 데이터 오염 주의:**
  * 카테고리 상단 `전체 체크` 실행 시 이미 체크되어 있던 항목의 금액이 가계부에 이중 합산되어서는 안 됩니다.
  * `전체 해제` 및 `삭제` 시에는 이미 가계부에 기록된 실제 지출 데이터가 사용자 동의 없이 증발하지 않도록 보호 규칙을 준수하세요.
