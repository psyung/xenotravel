# XenoTravel 개발 경고 사항 및 절대 금지 규칙 (Guardrails)

과거 패치 및 라이브 QA 과정에서 발견된 결함이 재발하지 않도록, 모든 수정과 기능 추가 시 아래 규칙을 반드시 검증해야 합니다.

---

## 1. 브랜드 및 디자인 관련 절대 금지 규칙
* **[금지] 기본 파란색 Primary 스타일 복귀 금지:** 버튼, 활성 탭, 지도 핀, 경로 선, 포커스 링에 `#2563EB` 계열 파란색을 사용하지 마세요. 반드시 차콜(`#18181B` / `#F4F4F5`)과 테라코타 코랄(`#D94E34` / `#F2745B`) 토큰을 사용하세요.
* **[금지] 비행기 아이콘 사용 금지:** 헤더, 홈 화면, 파비콘, 빈 상태 일러스트 어디에도 비행기 아이콘을 넣지 마세요. 브랜드 심볼은 `public/icons/logo-xeno-route.svg`만 사용합니다.
* **[금지] 투박한 언어 `<select>` 박스 재도입 금지:** 언어 전환 UI는 반드시 `KO EN 中 日` 인라인 텍스트 버튼 그룹으로 유지하며, 중점(`·`)이나 지구본 알약 버튼을 추가하지 마세요.
* **[주의] 파비콘 다크 브라우저 탭 가독성 보장:** `public/icons/logo-xeno-route.svg`는 OS 다크모드가 꺼져 있어도 브라우저 다크 탭(`#202124`) 위에서 선명히 보이도록 밝은 원형 배지 배경(`#FAF9F6`)을 유지합니다. (단, 앱 헤더 인라인 로고는 투명 배경을 유지합니다.)
* **[주의] 토스트 액션 버튼 WCAG AA 대비(4.5:1 이상) 준수:** `'실행 취소'` 등 토스트 내부 버튼은 라이트/다크 모드 모두에서 명도 대비 `4.5:1` 이상을 반드시 충족해야 합니다.

## 2. 상태, 지도 및 터치 인터랙션 버그 방어 규칙
* **[경고] 지도 일차 필터 우선순위 유지 (`B1`):** `'종류별'` 카테고리 필터를 활성화하더라도 현재 선택된 일차 밖의 핀은 절대 밝아지거나 펄스 애니메이션이 켜지면 안 됩니다.
* **[경고] 모바일 '지도' 전용 탭 높이 제한 오적용 금지 (`B5`):** `340px` 높이 제한은 일정 목록과 지도가 한 화면에 같이 있을 때만 적용하세요. 모바일 독립 `'지도'` 탭에서는 하단 탭바 위까지 전체 높이를 사용해야 합니다.
* **[경고] 보관함 `.inbox-dock` 및 `<select>` 입력 숨김 충돌 금지:** 모바일 키보드 대응용 하단 고정 바 숨김 규칙에 보관함 내부 `<select>`를 포함하지 마세요. 또한 바깥 클릭 닫기 리스너에서 `.inbox-dock`과 `<select>`는 반드시 제외해야 합니다.
* **[경고] 장소 카드 바깥 클릭 닫기 시 모바일 드래그 오작동 금지:** `pointerdown`과 `pointerup` 간 이동 거리가 `8px` 미만인 단순 탭일 때만 카드를 닫고, 지도 캔버스 내부 클릭 시에는 닫지 마세요.
* **[경고] 샘플 여행 사용자 편집 데이터 덮어쓰기 금지:** 사용자가 기본 샘플 여행을 한 번이라도 수정하면 `isUserModified = true`로 마킹하고, 이후 언어 전환 시 사용자 데이터를 절대 덮어쓰지 마세요.

## 3. 외부 서비스 약관, 공유 및 데이터 회귀 방지 규칙
* **[금지] Esri 지도 타일 영구 Service Worker 캐싱 금지 (`B10`):** 이용 약관 준수를 위해 Esri 타일 요청은 Service Worker에 장기 저장하지 말고 브라우저 기본 HTTP 캐시만 사용하며, 완전 오프라인 시에는 SVG 벡터 미니맵 폴백으로 전환하세요.
* **[금지] 미배포 `/api/share` 호출 금지 (`B9`):** 백엔드 단축 URL 서버가 배포되기 전까지는 `/api/share` 요청으로 404를 유발하지 말고 클라이언트 압축 URL과 글자 수 게이지를 사용하세요.
* **[경고] 시간 겹침 배지 일괄 밀기 오작동 방지 (`B7`):** 귀국편 출발 이후 시간 충돌에는 `'30분 밀기'` 버튼을 노출하지 마세요.
* **[금지] `'예상 걸음(0걸음)'` 부활 금지:** 보행 경로 연동 없이 `0걸음`으로 고정 노출되던 요약 배지는 폐기된 항목입니다.
